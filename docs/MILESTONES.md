# Milestone plan

## M0 — Foundation (complete in first slice)

Brand, specification, threat model, architecture, data model, screen map, milestone plan, and interactive deterministic demo.

## M1 — Real NEAR spine (2–3 days)

NEAR testnet wallet sign-in; strategy manifests anchored on-chain; real 0.10 USDC test payment or test token; grant issuance/revocation contract; event indexer. Keep encrypted content in a simple object store.

## M2 — Intents execution (2–3 days)

Integrate 1Click/NEAR Intents quote flow; bind quote to strategy and follower-policy hashes; execute one cross-chain testnet route; show explorer receipt and failure states.

## M3 — Privacy and proofs (2 days)

Client-side field encryption, scoped key envelopes, delayed release worker, wallet-linked aggregate metric computation, assurance labels, proof freshness, and negative tests for unauthorized fields.

## M4 — Fork economics (1–2 days)

Immutable parent link, semantic diff, fork publishing, access settlement split, upstream royalty receipt, public lineage graph.

## M5 — Developer + thesis track (1–2 days)

Typed SDK and REST/MCP endpoints; agent buys/evaluates/forks under a budget policy. Add one reproducible thesis with pinned dataset, notebook/model hash, parameters, and deterministic output.

## M6 — Submission hardening (1–2 days)

Public deployment and repository, seed accounts, 3-minute script, fresh-wallet test, mobile pass, error recovery, security boundary diagram, honest integration matrix, demo video/post, README quickstart, automated smoke test.

## Cut line

Must work: wallet, grant payment, scoped read, fork diff, follower policy, one Intents execution, royalty, revoke/expiry, lineage, public proof card. Cut before compromising these: rooms, NFTs, full social feed, multi-level royalties, advanced AI, production ZK proofs.
