# Screen map

1. **Discover feed** — proof-ranked strategy cards, assurance filters, privacy/access badges, creator and fork activity.
2. **Creator profile** — verified aggregate performance, risk, observation window, proof freshness, strategies, forks, revenue.
3. **Strategy workspace** — overview, thesis, evidence, positions, rules, versions, lineage, performance, access terms.
4. **Access checkout** — capability type, exact scopes, duration/delay, price, license, expiry, wallet payment.
5. **Scoped reader** — only granted fields, countdown, watermark, revoke/expiry state.
6. **Fork studio** — parent/child diff, allocation and risk edits, license/royalty preview, publish action.
7. **Execution review** — proposed intent, follower limits, policy result, quote, wallet confirmation, receipt.
8. **Lineage graph** — public version/fork graph, aggregate child outcomes, no restricted values.
9. **Creator console** — publish versions, configure disclosures/pricing, grants, revocations, revenue splits.
10. **Developer portal** — API keys, scopes, SDK snippets, webhooks, usage and audit events.

The vertical slice combines screens 3–8 into one demo cockpit so judges can complete the story without navigation overhead.
