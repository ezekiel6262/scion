# Scion hackathon demo

The submission-ready video is [`scion-hackathon-demo-2026.mp4`](./scion-hackathon-demo-2026.mp4). It is 3 minutes 33 seconds, uses an American male voice, includes burned-in captions, and shows the deployed product at [scionhub.xyz](https://scionhub.xyz).

Source materials kept in Git are the narration, shot plan, frame timing and SRT captions. Raw screenshots, the generated WAV and the local Piper voice model are ignored to keep the repository compact.

The demo distinguishes live infrastructure from seeded **Demo** records. It does not claim that a funded autonomous mainnet trade was made during recording; it shows the deployed owner-controlled execution path and its safety boundary.
