# Security policy

Do not open a public issue for a vulnerability or include secrets, private keys, personal data, or exploitable transaction details in public.

Until a dedicated disclosure mailbox is published, contact the repository owner privately through the email on their GitHub profile with the subject **Scion security report**. Include the affected commit/deployment, reproduction steps, impact, and suggested mitigation. Do not move funds, access data that is not yours, or test against other users.

Scion is pre-audit hackathon software. It must not custody funds or receive seed phrases. Autonomous agent execution is safety-paused and is not represented as production-ready.
